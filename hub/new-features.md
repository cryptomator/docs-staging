# New Features

**Cryptomator Hub 2.0.0** introduces the following new features:

* [User & Group Management](/hub/user-group-management/.md) — Manage users, groups, roles, and permissions directly in Hub
* [Emergency Access](/hub/emergency-access/.md) — Restore access to a vault in case of account loss or ownership issues

The [Admin Guide](/hub/guides/admin-guide/.md) walks through both features in a worked example: see [Add Users and Groups](/hub/guides/admin-guide/.md#add-users-and-groups) and [Enable Emergency Access](/hub/guides/admin-guide/.md#enable-emergency-access).
