# New Features

**Cryptomator Hub 2.0.0** introduces the following new features:

* [User & Group Management](/hub/admin-guide/user-group-management/.md) — Manage users, groups, roles, and permissions directly in Hub
* [Emergency Access](/hub/admin-guide/emergency-access/.md) — Restore access to a vault in case of account loss or ownership issues

The [Admin Guide](/hub/admin-guide/quick-start/.md) walks through both features in a worked example: see [Add Users and Groups](/hub/admin-guide/quick-start/.md#add-users-and-groups) and [Enable Emergency Access](/hub/admin-guide/quick-start/.md#enable-emergency-access).
