# Self-Hosting Guide

This guide is for everyone who runs a Cryptomator Hub instance on their own infrastructure. It covers a local test instance, the way from there to production, and the maintenance tasks that follow.

If you want to see Hub in action first, start with the [Quick Start](/hub/self-hosting-guide/quick-start/.md). It gets a test instance running on your machine in about 10 minutes and then continues to production.
